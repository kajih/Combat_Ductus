# Body Type is cosmetic-only

The three Body Types (Small, Medium, Large) exist so each employee's Character can match their real-world proportions for recognizability — not to create weight-class-style gameplay variety, which is how most fighting games use body size. Body Type has zero effect on stats, speed, hitboxes, or damage; every Character plays identically regardless of Body Type. This trades away mechanical depth in exchange for recognizability and fun/social value, and it means new Characters can be added to the Roster later without any balancing work.
